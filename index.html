Pengaturan Aplikasi

Kode Google Apps Script

Langkah Setup Multi-User Google Sheet:

  1. Buka Google Spreadsheet yang digunakan tim.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Ganti seluruh kode dengan kode di bawah.
  4. Klik Deploy > New Deployment. Pilih type Web App.
  5. Atur Execute as: Me dan Who has access: Anyone.
  6. Salin Web App URL dan tempelkan ke Pengaturan.
